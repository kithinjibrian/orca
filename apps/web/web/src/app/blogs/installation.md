# Quick Start

Create a new Orca app and run it locally

---

## Prerequisites

- Node.js - v20.9 and above
- Text editor - vs code
- Terminal - for running CLI commands

## Install Pod CLI

Open a terminal and run the following command:

```bash
npm install -g @kithinji/pod
```

## Create a new project

In your terminal, run the CLI command `pod new` with the project name. In the following examples, we'll be using the example project name of `my-app`

```bash
pod new my-app
```

The command will scaffold an Orca project which will get you started quickly. Switch to the project.

```bash
cd my-app
```

And then start it.

```bash
npm run dev
```

If everything is successful, you should see a message in your terminal:

```bash
> web@0.0.0 dev
> pod dev

Server started
```

And now you can visit the path in `Local` (e.g., `http://localhost:8080`) to see your application. Happy coding! 🎉
